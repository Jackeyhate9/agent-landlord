# Contributing

Install Python 3.11+, Node 20+, Go 1.23+, Docker and Compose. Run `python -m pytest`, `npm --prefix apps/web test`, `npm --prefix apps/web run typecheck`, `npm --prefix apps/web run build`, and `go test ./...` from `bridge/` before submitting.

Keep rules and settlement deterministic. Add behavior tests at a public seam before implementation. Never include provider keys, participant secrets, incompatible source code, copyrighted audio, or hidden opponent cards. User-facing changes must preserve the Arena Token notices in both languages.
